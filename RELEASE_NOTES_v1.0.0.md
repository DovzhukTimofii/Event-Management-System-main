# Event Management System v1.0.0

## Статус

Стабільна навчальна версія MVP, зафіксована для подальшої роботи та демонстрації.

## Основні можливості

- реєстрація та вхід користувачів;
- JWT-авторизація та розмежування ролей;
- перегляд списку подій;
- перегляд детальної інформації про подію;
- створення та перегляд власних реєстрацій на події;
- видалення реєстрацій;
- надсилання оцінок і відгуків;
- адміністративне створення, редагування та видалення подій;
- REST API для Front-end і Back-end взаємодії;
- обробка loading, empty та error станів на ключових Front-end сторінках;
- адаптивний інтерфейс для основних сценаріїв;
- окрема API-документація у `server/API.md`.

## Технологічний стек

### Front-end
- React 18
- React Router
- Axios
- JavaScript
- CSS

### Back-end
- Node.js
- Express.js
- JWT
- bcryptjs
- MySQL через `mysql2/promise`

## Структура

- `client/` — клієнтська частина;
- `server/` — серверна частина;
- `server/API.md` — документація REST API;
- `README.md` — загальний опис проєкту.

## Важливі зміни, що увійшли до v1.0.0

- додано валідацію реєстрації та входу;
- додано документацію API;
- покращено безпечне налаштування підключення до бази даних;
- додано користувацькі повідомлення про помилки у Front-end;
- покращено адаптивність сторінки `MyBookings`;
- додано `server/package.json` для окремого запуску Back-end;
- Front-end API URL винесено у `REACT_APP_API_URL` з локальним fallback;
- підготовлено конфігурацію MySQL до роботи з різними змінними середовища.

## Відомі обмеження MVP

- адміністративні endpoints `/api/admin/bookings` і `/api/admin/feedback` наразі повертають порожні масиви та залишені для подальшого розширення;
- автоматизований CI/CD не налаштований;
- production deployment не є частиною цієї стабільної навчальної версії;
- міграції бази даних не автоматизовані.
